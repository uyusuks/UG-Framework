# UG-Framework ~ [Uyusuk's-Guild]

### --This repo based on an open-sourced guild framework that i did create from the begginin' if any questions/suggestions, dm on discord ".muriel."

### Available Perks;

`/gcmds & /gcommands` --> [lists available commands]
<br>
`/crg` --> [creates guild with already set default-props]
<br>
`/request` --> [to invite players to the current guild]
<br>
`/accept` --> [to accept request thats already sent, has 30 secs of cooldown to decide]

### Incoming Perks;

`/decline` --> [to decline request thats already sent, has 30 secs of cooldown to decide]
<br>
`/kick` --> [kick the target player thats inside of the current guild]
<br>
`/gchat` --> [guild-only chat]
